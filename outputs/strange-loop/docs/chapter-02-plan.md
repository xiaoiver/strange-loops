# 第二章：图形与衬底

当前动线（2026-10-27）：《龙虾》双海报 → 标志墙 → Rubin 共边墙 → 穿过花瓶进入第三章。共边墙从中央独立展品移到游线尽头，观察的留白成为真实出口。不加入数字墙、数学问答、完成徽标或观看时长门槛。

## 游览与导航

1. 两位同行者穿过第一章 WU／MU 出口，经侧墙入口抵达两款《龙虾》海报。「走向标志墙」继续主线。
2. 右侧墙并置 Formula 1、FedEx 与 Toblerone 三个单色标志。「看留白」与「填回墙面」切换真实镂空；「走向共边墙」继续，「走向海报」可回看。
3. Rubin 共边墙位于展厅后方。混凝土侧翼和过梁接到侧墙及顶板，两个侧脸之间保留贯通的花瓶空隙，能看见后方同轴的第三章立方体。先观察侧脸，再以「看留白」切换到花瓶读法，主按钮变为「穿过留白」。
4. 镜头与同行者穿过同一个开口进入第三章，返回也走原路。海报和标志墙页脚的「走向出口」先到共边墙，不从侧面直接跳进第三章。章节地图继续允许自由跳转。

## 空间与动作

- 沿用黑白纸灰、哑光 PBR、PCSS、AO、FXAA 与既有天光，不增加景深或装饰性灯光。
- `gallery-layout.js` 统一共边墙位置 `z=-6`；原始 Rubin 曲线保留，侧翼及过梁补全建筑边界。
- 第三章立方体位于 `[0,-1.8,-16]`，从开口就能看到同一实体；不复制模型、不为预示额外运行分形距离场。
- 相机停靠点、穿越控制点、角色路线和返回路径使用同一位置。阅读继续独立于角色到位时间；减弱动态直接切换。
- 标志墙仍与原建筑墙齐平，标志保留薄浮雕。完整 F1 留白、FedEx 箭头、Toblerone 山脊与熊形共用有来源的矢量轮廓和后备 SVG。

## 内容与状态

页面展签统一显示作品、作者、年份和来源；墙上不重复放展签。Rubin 标注 Edgar Rubin、1915；Formula 1 标注 Carter Wong、1994–2017；FedEx 标注 Lindon Leader、Landor、1994；Toblerone 展示年份按包装改版标注 2000，设计者为 Andrew Davidson，日期依据详见素材声明。解释只保留对图底关系的简短观察，不描述填块机关动作。

独立存档键保持 `geb.figure-ground.v1`，内容版本为 6：

- `posters`：海报，前往标志墙。
- `marks`：标志墙，刷新后仍回到这里。
- `faces`：共边墙侧脸观察。
- `ground`：花瓶与出口，前往第三章。

版本 1–5 保留原有观察阶段，不要求重游；旧数字墙数据不恢复。回看不清空进度。七语言、键盘焦点、Esc、减少动态与 SVG 后备模式共用导航状态。
