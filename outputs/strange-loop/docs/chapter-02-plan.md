# 第二章：图形与衬底画廊

当前范围按 2026-10-27 更新：保留《龙虾》双海报与 Rubin 共边墙，加入 FedEx 字标的负空间延伸案例。原有生成合数、检查 11、理解问答与完成标记不属于本版流程；旧方案可在 Git 历史中查阅。

## 叙事与动线

两位同行者穿过第一章的 WU／MU 出口，从画廊侧墙入口出现，先沿墙走到《龙虾》双海报。两次拥抱中的留白，使缺席的人仍可被辨认。

点击「走向共边墙」，两位角色走向由侧脸轮廓组成的两片墙体。先看见面对面的两张脸，点击「看留白」后，以乌龟的简短回应引导发现中间的花瓶。几何保持原样，不用描边强调答案。

看过 Rubin 留白后，可继续「看字母间的留白」，走向右侧墙面的 FedEx 字标。先不提示答案；点击「看留白」时淡化完整字标，以同一位置的箭头轮廓显示 E 与 x 间的负空间，点击「回看字标」恢复。字母不移动，提示明确标为留白示意。展签标注 Lindon Leader、Landor、1994 年和设计师访谈。可回到共边墙或海报，也可从页脚走向第三章；不设观看时长、答题或通关门槛。

## 空间

- 延续已认可的黑白纸灰、哑光 PBR、PCSS 柔光与 AO。
- 一道真实顶部开口形成斜向天光与建筑投影；保留现有光源和构图。
- Rubin 花瓶用原创共边曲线挤出两片有厚度的墙体，中间是真实空隙。
- 两款用户指定的《龙虾》海报等高并置，保留原始画幅。
- 移除数字牌、算式、试除说明、证据标记和对应相机位；角色在海报、共边墙与右侧字标之间游览。
- 不增加景深、音频或墙面重复展签；FedEx 的留白提示仅在用户选择时出现。

## 页面展签与原创对白

《龙虾》页面展签列出作品名、2015 年、海报设计者 Vasilis Marmatakis、原创短评及两条分别对应海报的 Dazed 来源。

Rubin 花瓶展签沿用同一排版，列出 Edgar Rubin、1915 年图底知觉研究、原创说明和原始研究链接。年份指研究发表年份，当前墙体与 SVG 均由本展原创绘制。

所有对白为原创致敬，不引用原书对话。沿用中文竖排姓名与英文横排姓名的对话样式，不设置角色姓名切换按钮。

## 状态与访问

独立存档键保持 `geb.figure-ground.v1`，内容版本为 5，仅记录是否经过海报段和是否观察过留白。

- 起点 `posters`：主按钮「走向共边墙」。
- `faces`：主按钮「看留白」，可回看海报。
- `ground`：保留花瓶观察对白，主按钮「看字母间的留白」，保留回看海报入口。
- 重新回看展品不重置观察进度；不显示「已完成」。
- 版本 1–3 的有效观察记录迁移保留，旧数字阶段回到共边墙，不恢复数学问题。
- 返回第一章、序厅及打开下一章预告均不设门槛。

FedEx 观察为临时展项状态，不改写既有观察进度；切换语言保留箭头提示，Esc 先回到之前的观察阶段。无 WebGL 时显示同一矢量和箭头示意。

七种语言共用状态。语言切换保留观察对象，刷新后恢复观察阶段。无 WebGL 时使用 SVG 共边轮廓与 HTML 双海报、展签和相同导航。

穿门过渡沿用第一章出口与新画廊入口的实际开口，角色跨过门槛后才切换空间。减弱动态和后备模式直接进入。键盘保留可见焦点，Esc 优先关闭预告、收起回看，再返回序厅。
