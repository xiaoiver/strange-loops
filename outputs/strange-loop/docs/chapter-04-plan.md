# 第四章：螃蟹卡农庭院

状态：2026-10-23 本地实现，分支 `feat/crab-canon-courtyard`，尚未发布至 GM。

## 主题与原书

前章“和声小迷宫”让访客逐层进入、逐层返回，在父层接续未完的乐句。这一章从层次转向读法：同一份有限材料，从另一头读，能否仍构成有意义的东西？

本展第四章对应 GEB 的对话《螃蟹卡农》（Crab Canon），并非原书第四章。该对话位于原书第八章 Typographical Number Theory 之前。它借用巴赫《音乐的奉献》中螃蟹卡农的结构，把相向读取的声音转换为两位角色的对话：围绕螃蟹的中央段落，整句对白按相反顺序重现，角色交换。

本展只致敬这种组织方式，不复刻原文或巴赫乐谱。逆行指音符事件顺序倒过来，音高和时值随事件保留；不倒放录音，不逐字倒读句子，也不把它混同于音程倒影。原乐句刻意不写成回文，让正向与逆向确实不同。

参考：

- [MIT OCW：GEB 课程阅读安排](https://ocw.mit.edu/courses/es-258-goedel-escher-bach-spring-2007/pages/readings/)，Crab Canon 与第八章对应。
- [原书文本镜像](https://ru.djvu.online/file/0uq7KxBnWwJe8)，Crab Canon 对话与后文对其创作结构的讨论。对白与展厅文案均重新创作。

## 从第三章进入

画廊右侧墙上增加真实侧门，门后延伸为同材质庭院。访客在第三章点 footer 的“走向螃蟹卡农庭院”：如尚在模型内部，先退出至外层观察位，然后沿一条连续曲线穿门，不在中间节点重复停顿。乌龟说：“也许，另一头才刚开始。”

相机按弧长推进，起止缓停；视线按方向平滑转向，避免越过注视点。两位角色沿地面路线走过同一扇门，镜头到位后即可操作，不等待角色走完。返回穿过原侧门，并恢复第三章原有层次存档。

## 庭院与玩法

纸灰地面、两面素墙、六枚石墨灰音块和一件小比例原创螃蟹雕塑。音块高度映射音高，没有中心高台、纹理噪点或新增外部模型。实心与空心游标表示两个声部，抬到音块上方保持可见；当前音块同时变亮。阿基里斯与乌龟站在路径两端，小螃蟹位于中央后方。

流程只有一个主操作：

| 步骤 | 操作与变化 | 想让访客发现 |
| --- | --- | --- |
| 从这一头开始 | 实心游标正向读取六音，相机偏向一端 | 音块是一段按时间展开的材料 |
| 从另一头开始 | 空心游标逆向读取同一组六音，相机移向另一端 | 方向改变，来源没有改变 |
| 两头，同时开始 | 两个游标相向，两个声部同时演奏，相机回到较高总览 | 同一材料可以承担两种角色 |
| 改一处，再走一遍 | 轻点一个三维音块或对应键盘按钮，改变共享源音，再次双声部读取 | 一处改动在两种读法里出现在不同的时间位置 |

单声部约 9 秒，双声部约 12 秒，均为有限乐句，没有自动循环。播放中主操作变为“继续”，允许提前到下一步，无分数、测验、倒计时或通关限制。footer 始终保留前章与第五章预告。完成前三种读法后才出现小型改音区，可恢复原乐句、从头漫游、展开全文对白。

## 对白与声音

原创对白围绕中央螃蟹形成七句结构：

1. 阿基里斯：这条路有尽头吗？
2. 乌龟：看你从哪头出发。
3. 阿基里斯：那我们一起走。
4. 螃蟹：我就在中间等你们。
5. 乌龟：那我们一起走。
6. 阿基里斯：看你从哪头出发。
7. 乌龟：这条路有尽头吗？

单声部先分别展示前三句的正读和倒序角色交换，双声部阶段再展示完整结构。对称的是整句的位置与说话人的互换，不要求每句话脱离语境后字面完全相同。

原创六音素材为 C4–E4–G4–B4–C5–G4，两声部使用轻量振荡器、不同音色和轻微左右声像。改音从 C 大调音列中循环选择，并保持相向配对音的协和音程，减少随机改动产生的突兀感。这不是巴赫作品的复原。

音乐默认关闭，不沿用第三章的开启状态；未开启时不创建音频上下文。游标、音块、说明和对白提供完整的静音体验。只有主动开启音乐且开始走一遍才发声；静音、离章、后台切换均淡出并取消后续音符，迟到的音频恢复不会重新播放离开的章节。

## 实现与边界

- `crab-system.js`：共享六音、逆行事件、有限读法、对白索引与独立存档 `geb.crab.v1`。
- `crab.js`：HTML、焦点、播放时钟、可选改音、音乐按钮、返回与预告。
- `crab-scene.js`：原创几何、相机轨迹、游标、音块高亮及射线点击。
- `crab-audio.js`：用户主动开启的原创 Web Audio 合成。
- `crab-copy.js`：中文、英文、日文、韩文、法文、德文和西班牙文。

刷新回到序厅，经地图重新进入后恢复本章阶段与源音；音乐重新关闭。无 WebGL 用 HTML 音块及同一状态机完成体验，音频不可用不阻断操作；减弱动态直接切换相机，游标按音符位置切换。手机保留单主按钮和小型改音区，长对白收在可展开、可滚动区域。

本次不做作曲编辑器、不讲授乐理、不要求找回文、不引入自由漫游或角色自动替玩家解题。成功标准是访客能复述：“同一段材料，换个方向，就成了另一个声部。”
