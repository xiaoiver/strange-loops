# 第三章：和声小迷宫

本地实现范围：第二章的共边空隙、连续通路、画廊模型的尺度变化、建筑折叠、两次进入和逐层返回。约两分钟，按玩家操作推进；没有寻路岔口、问答、观看时长或章节通关锁。代码和文案支持现有七种语言。

## 原书联系与原创改编

展览第三章取材于原书第五章《递归结构和递归过程》及其前置对话《和声小迷宫》，不与原书章号一一对应。参考 [MIT 对话讲义](https://mitocw.ups.edu.ec/high-school/humanities-and-social-sciences/godel-escher-bach/lecture-notes/MITHFH_geb_v3_12.pdf)中的层次进入、退出与栈的关系。

本展把“嵌套—暂停外层—在内层停止—返回继续”做成原创的建筑模型与短对白。几何展品与对白不复刻原书场景，不使用原书文字、埃舍尔原画或巴赫录音。本章先建立可返回的层次，为之后的自指与怪圈留下空间。

## 与第二章的连续过渡

共边墙中间一直是真实空隙。将后墙向后延伸，地面保持同高、同材质，在墙后设置一件轻薄展桌及画廊模型。模型在第二章已存在，可以透过空隙隐约看到。它与展桌之间保留一段空隙，轻微上下悬浮，为进入后的尺度错位留下提示。

页脚“走向和声小迷宫”引导镜头靠近共边墙、沿 x=0 穿过开口，再停在模型前。镜头使用约 4.2 秒的连续曲线，按弧长推进，只在整段起止缓停；开口内保持中线，眼高从两个观察位平滑衔接，不在中途俯冲或停顿。观察位移到墙后约 3.4 个单位，留出转弯余量，构图偏移同步过渡。两个角色从当前站位接近开口，沿开口中心逐个穿行，步频跟随实际位移。镜头到位后恢复阅读，人物继续走完路线。减少动态时直接到达。

返回第二章时沿同一开口反向穿行，共边墙、天光和海报保持空间位置；恢复共边墙的观察位与页面展签。地图可直接进入第三章，或跳到任意已开放章节。入章不依赖已观察过留白。

## 递归体验

| 所在层 | 场景与原创对白 | 主操作 |
| --- | --- | --- |
| 画廊 | 矮展桌上有刚走过的画廊模型，可辨认双海报和侧脸墙。“里面也有一间展厅？” | 走进模型 |
| 模型中的画廊 | 微缩展厅长成脚下的房间，展桌成为上方巨大框架；下一间展厅竖直折在墙上。“外面那一间，先留着。我们还会回来。” | 展开下一层；可提前返回 |
| 模型里的模型 | 墙上的展厅沿前缘翻落、展开为脚下地面；空的混凝土框成为终点，没有更深的模型。“这里没有下一间了。从这里，回到刚才。” | 回到上一层 |
| 返回模型中的画廊 | 内层重新折回墙面，外层沿原尺度恢复；暂停的运动展品从原位置接续。 | 回到上一层 |
| 返回外层画廊 | “原来不是重新开始，是接着刚才。” | 再走一遍 |

模型是场景图中真实嵌套的两组几何。此次空间改版以《盗梦空间》的尺度错位与折叠建筑作为视觉启发，使用原创展厅几何，不增加电影资产。两次进入有不同的空间动作：

- **第一次：模型长成房间。** 展厅从 0.24 倍平滑长到 1.15 倍，地面落回原展厅地坪；原展桌放大六倍，保留为上方开放框架。桌面使用四边框而非实心板，不在展开后封住视野。
- **第二次：墙面折成地面。** 下一间展厅以正面边缘为铰链，从竖直状态展开为水平地面，同时向前延展。整片地板保持在父层地面之上；内外墙体保留高度差与轮廓，让外层仍可辨认。最内层的地板只保留开放结构边框，避免折起时遮成一堵实墙；中央只有一座有厚度的混凝土空框，不再递归；没有海报、共边墙或更小的模型。
- **镜头稳定。** 建筑承担尺度与 90 度旋转，镜头保持世界竖直方向，不侧滚、不绕飞、不俯冲。第一步缓慢向前约 2.4 单位并轻抬视线；第二步继续向前约 2.1 单位，观察方向保持一致。展开与返回采用同一条连续布局，约 3.8／4.2 秒，端点速度和加速度均为零。
- **外层暂停，返回接续。** 微缩房间的轻微悬浮、第一内层悬置骨架的倾转分别跟随各自的时间；建筑变化过程中所有层暂停。返回后父层从原来的位置继续运动，与音乐保存的乐句位置相呼应。最后的空框保持静止。
- **退出先收回。** 从内层返回第二章，先恢复外层模型，再走原有通道。地图跳转直接取消当前动作；恢复存档时直接得到该层完整建筑，不留半折叠状态。

外层常规展厅在第一次深入时逐渐淡去，露出悬置于空白中的巨大建筑框架：不同朝向的框架带有纵深与真实阴影，属于第一内层的时钟，缓慢倾转；进入第二内层时它们停住，返回后继续。第二次展开时，包围的墙面、展桌框架和悬置骨架退入留白，只剩一座可真正看穿的空框。框后没有下一层，终点自身静止，以有限停止条件收束；逐层返回时原建筑与展品逆序恢复。各层保留对应的 HTML 所在位置和一句说明，第一层主按钮改为“展开下一层”；不增加分数、进度条或完成徽标。无 WebGL 保留三层嵌套图解与相同状态操作；减少动态直接切换建筑与观察位，建筑也保持静止。

角色留在外层模型旁。建筑展开为内层房间后，外层角色及其阴影暂停显示，避免巨大的角色或阴影干扰内部模型；返回外层后继续原路线与待机。内层短对白仍以同行者的原创提示呈现。

## 音乐与调性归路

使用 Web Audio 合成原创短曲，没有录音、采样或在线音频依赖。音乐不是循环背景，而是与操作对应的有限乐句：C 大调 → G 大调 → D 大调 → G 大调 → C 大调。

- 音乐默认关闭，仅点击“开启音乐”才启动音频；未开启时进入和返回均不发声。进入第一层用共同和弦与 D7 中的 F♯ 建立 G 大调；进入第二层以 A7 中的 C♯ 建立 D 大调。
- 每层的前半乐句播放后等待操作。进入时保存父层下一音的位置；转调短句随镜头移动播放，目标层前半乐句等待镜头到位后接入。首次快速进入仍先给出外层主题的起句。
- 最内层以 D 大调作局部收束。逐层返回恢复父层尚未播放的乐句，再接后半句；最后通过 G7 恢复 F 本位，补完 C 大调终止式。音量克制，没有无限播放或必须听完的时间锁。
- 所在层旁显示当前调性，静音和音频不可用时仍可辨认层次。低优先级的“开启音乐／静音”控制在本次游览中保留状态，刷新后恢复关闭；后续操作不覆盖静音选择；切换语言保留音乐进度。
- 离开章节、进入后台或卸载页面时淡出并取消后续音符。后台恢复只接续仍处于本章的音频；迟到的 AudioContext 恢复不会让已离开的章节重新发声。无音频设备、Web Audio 不可用或启动失败均不影响场景操作。

这是对原书调性与嵌套关系的原创改编，不把同名历史曲目的录音当成精确复现。

## 界面、状态与后备路径

- 主界面沿用中性灰清水混凝土、中文宋体、真实天光、阴影和 AO。活动建筑使用明确的物体局部材质坐标，纹理与凹槽随墙体一起缩放和转动，不在 0.5 倍尺度上切换坐标系。左侧只保留章名、所在层、短说明、当前对白与主操作；前后章节导航放在 footer。
- 存档 `geb.labyrinth.v1` 独立于前两章，保存层次、是否到达最内层及是否完整返回；提前退出、刷新和语言切换均保留阶段。非法层次重置，未到最内层的提前返回不会被标记为完整往返。由第二章步行入章时，若存档在内层，从外层模型连续推进到存档层，不在门口直接跳切。
- 镜头移动时禁止重复进入，footer 仍可退出；离章取消镜头回调，防止旧回调重建隐藏界面。Esc 先关闭原生预告或章节地图，再退回一层，外层则返回第二章。
- 无 WebGL 时显示三层嵌套的 SVG 图解、同一文案和相同操作，状态逻辑共用。减少动态模式直接呈现相应观察位。
- 七种语言覆盖全部新按钮、对白、位置名称和下一章预告；切换语言不回到初始阶段。

## 验证要求

验证完整两进两出、提前返回、切换章节打断移动、刷新恢复、七语言切换、390 × 844 手机布局、键盘 Enter／Esc、减少动态和无 WebGL 路径。相机和角色必须穿过真实空隙；手机外层观察位位于共边墙背面，避免墙体挡住模型。序厅和前两章的规则、海报、字母堆及角色动作保持正常。

单元测试覆盖停止条件、逐层返回、存档边界、七语言字段、实际角色路线、两种尺寸的相机返回位置及取消回调、减弱动态直接完成。生产包继续验证字体子集与所有语言页面；新增资源均来自原有模型、海报和原创几何，无新的在线加载依赖。
