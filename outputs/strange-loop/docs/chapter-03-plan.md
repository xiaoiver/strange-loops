# 第三章：和声小迷宫

2026-10-26：将已确认的无限分形空间接入正式第三章。外部保留实体门格海绵与清水混凝土展厅；中央孔洞直接显现内部，穿过后可持续漫游、暂停环视或返回展厅。替代之前两只立方体的两层放大与空心停止点。

## 叙事与边界

第三章以原创空间致敬 GEB 的递归主题，不复现原书的具体场景或对白。门格海绵的几何自相似让访客直接看到「同样的结构在内部不断重现」；进入与返回保留外部展陈参照。无限前进是本展的艺术表达，不将分形自相似等同于所有递归过程，也不声称数学结构具有无穷精度。

采用程序化生成的门格海绵。每次三等分为 27 块，去掉中央及六个面中心的 7 块，对剩余 20 块重复相同规则。数学背景参考 [圣保罗大学数学展馆](https://matemateca.ime.usp.br/acervo/fractais_ingles.html)与 [IIT 的 Karl Menger 介绍](https://www.math.iit.edu/Menger/menger_old.html)。网格、距离场和材质代码均为项目原创，无新增第三方画作、模型或贴图。

## 动线与操作

1. 从第二章的真实 Rubin 共边开口穿过，用原有 4.2 秒通路到达立方体前；阿基里斯和乌龟留在展厅观察。
2. 实体立方体边长 2.4，使用两次细分与原有清水混凝土。中央孔洞是一张实际位于开口的空间窗口，显示内部距离场。
3. 点击「走进孔洞」，以约 8 秒对齐中央开口并进入内部。角色在镜头实际跨过孔洞前一直留在展厅，随视锥自然离开画面；不按提前写入的存档深度隐藏。外部与内部共用方向、视野、8 倍坐标映射和线性光照输出；穿越处不切页面，不用黑屏掩盖进入。
4. 内部持续向前，通道缓慢弯曲，各纵深层改变倾角与尺度。镜头保持自身竖直方向，拖动可环视。暂停后可继续；滚轮与画布上的上下方向键手动前进、后退并暂停自动行进；空格暂停或继续。
5. 「返回展厅」可在进入途中或巡航时使用，以约 0.7 秒的纸灰过渡回到同一外部观察位。没有要求沿无限路径倒走，也没有强制停止层。Esc 先关闭弹窗或地图，再返回展厅；下一次 Esc 才返回第二章。
6. 可选音乐默认关闭，进入时从 C 转向 G，返回接续 C 的未完乐句；没有因漫游距离增长而无限创建音乐层级。

## 渲染

使用同一个 Three.js renderer 和 WebGL context。外部使用原有网格、PBR 灯光、PCSS、GTAO 与 FXAA；孔洞先将与内部相同的 GLSL 距离场渲染至受限目标，再用屏幕投影采样到实体平面。不会随着孔洞放大而在 Retina 全画布逐像素执行距离场。加载期间使用 compileAsync 预编译同一程序；进入内部不再链接第二份程序。

跨过门洞后，暂停常规 RenderPass 与 GTAOPass，只运行内部 FractalSpacePass，再由共用 OutputPass 与 FXAA 输出。距离场自行计算法线、粗糙介电 GGX 光照、软阴影与 AO，避免给全屏三角形套上展厅网格的深度遮蔽。窗口与内部共用固定预算的目标，再放大到画布；相机静止时复用该纹理，角色待机不会触发距离场重算。第三章后处理同样采用受限尺寸；当前视口的像素预算约为 134 万，其他章节保持原分辨率。角色动画保留，但第三章动态影子最多每秒刷新 15 次，显隐切换仍立即刷新。

桌面约 86 万像素、最多 136 步及 4 层细分；窄屏约 39 万像素、最多 100 步及 3 层细分。远界 185 个内部单位；持续低帧率可降低渲染比例。每 36 单位重置局部坐标，相位同步补偿，避免将持续增大的位置交给 GPU。资源、步数和细节不随游览距离累积。实际速度仍取决于设备和画面，不能保证所有手机固定帧率。

## 存档、语言与后备

七语言覆盖「立方体外／分形空间内」、进入、暂停、继续、返回、说明和键盘可访问性。沿用 `geb.labyrinth.v1` 存储键，内容升级到版本 2：只保存外部／内部、访问及返回状态，不保存无限距离。旧版 1、2 层均迁移为内部；刷新或从地图重进时恢复为静止内部，不自动开始移动。

减少动态偏好下直接定位；内部默认静止，主按钮为「向前一步」。无 WebGL 时继续使用静态重复结构图解和阅读／返回路径。退出章节取消未完成的进入回调，恢复展厅与其他章节的渲染。

单元测试包括实际穿过中央孔洞时的位置连续性、进入后持续巡航、暂停与大步手动探索、返回观察位精确恢复、途中返回与离章取消、旧存档迁移、减少动态、固定目标预算及暂停缓存。保留原有第二章通路、角色路线、音乐和发布资源验证。
