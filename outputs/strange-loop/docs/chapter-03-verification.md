| 流程 | 实际结果 |
| --- | --- |
| 第一章 → 第二章 | 原有出口路线、画廊入场和当前观察存档仍可使用 |
| 第二章共边墙 → 第三章 | 镜头与角色沿真实空隙穿过，过渡显示阿基里斯的原创短句，抵达后恢复导航 |
| 外层 → 模型 → 最内层 → 逐层返回 | 每层观察位和展品保持对应，最内层没有继续进入入口；完整返回后显示“再走一遍” |
| 提前 Esc 返回 | 第一层模型内可返回外层，主操作重新显示“走进模型”，不冒充完整往返 |
| 移动中退出本章 | footer 可退出；旧的层次镜头回调不会重新显示第三章 |
| 刷新后从地图进入 | 恢复独立存档，保留已返回状态；不覆盖第一章推导或第二章观察 |
| 七语言切换 | 章名、所在层、说明、对白、主操作及 footer 更新，当前层次与返回状态保留 |
| 手机英文及德文 | 标题、说明、长按钮与 footer 可读；修正外层镜头被共边墙遮挡、内层深色墙体干扰文字的问题 |
| 无 WebGL | 临时本地测试服务使 WebGL 上下文创建失败；SVG 嵌套图解与相同按钮完成两进两出 |
