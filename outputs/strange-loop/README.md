# 怪圈 · 序厅与 WU 花园

《集异璧》原创致敬叙事展。包含真实三维 G/E/B 交集雕塑、三束正交平行光和实时阴影、三个观察方向、拖动观察、章节地图，以及可玩的第一章 WU / MU 花园。第二章及后续章节尚未开放。

## 语言与文案

右上角 EN / 中文切换覆盖标题、原创角色对白、章节地图、第一章规则与观察线索、灯光和观察方向的无障碍标签。默认中文，通过 `localStorage` 的 `geb.locale` 记住选择；切换时保持视角、灯光与所在页面。

双语文本集中于 `src/copy.js`。中文参考商务印书馆术语 WU谜题、和声小迷宫、图形与衬底、艾舍尔；英文保留 MU-puzzle、Little Harmonic Labyrinth 等对应名称。文案均为原创，非原书引文。主线围绕形式、意义、自指与心智；阿基里斯和乌龟采用本地 Blender 原创建模与骨骼动画。

简介中的中文书名链接至商务印书馆官方介绍，英文 GEB 链接至英文维基百科书籍介绍。链接在新标签页打开，保留当前展厅。

## 预览

在此目录运行 `python3 -m http.server 4173`，然后访问 http://localhost:4173 。需通过 HTTP 打开，不能直接双击 HTML。网页成品已经构建，预览不需要安装 Node 依赖。

## 修改

`npm install` 后运行 `npm run build`，把 `src/main.js` 构建为 `assets/app.js`。页面布局在 `index.html`，样式在 `style.css`。更新发布版本时同步修改 HTML 中 CSS/JS 的版本查询参数，避免预览缓存。

## 第一章：WU 花园

- `src/miu-system.js` 是纯规则与历史引擎。内部统一使用 MIU / MI / MU，中文展示为 WJU / WJ / WU，语言切换不改推导数据。
- 规则 2 只复制 M 后的部分；规则 3、4 逐处匹配并保留重叠位置。唯一匹配点规则立即应用；多个匹配时点位置直接应用，并同步突出三维字母。
- 推导历史为父子节点树。回到旧节点后继续会保留原分支；重复同一条边复用原节点。完整历史、目标与已查看线索保存在 `geb.garden.v1`，恢复时重新验证每条推导边。
- 初次进入先做可达的 WUJU 练习，完成后可尝试不可达目标 WU；历史中的四步路径是一个证明。观察线索由玩家主动逐层打开：计数、三字母分组、检查所有规则的不变量说明。不把尝试次数当作“不可能”的证据。
- 展台限制单串 192 字符、600 个历史节点。超限会明确区分展示限制与数学规则，允许回到已有路径继续查看。清空足迹有独立确认。
- `src/garden.js` 负责 DOM 操作、键盘焦点与对话框；`src/garden-copy.js` 保存原创双语对白；`garden.css` 负责可滚动的小屏布局。`src/garden-scene.js` 提供规则桌与同步字串铭文，角色继续使用现有 GLB。
- 三维场景不可用时仍可完整操作规则；减少动态效果模式跳过镜头过渡与角色行走。第二章入口始终可用，但明确显示为预告。

深灰矮台上平放的实体字母随改写移动。真实顶光穿过矩形狭缝，在墙地形成连续亮带；墙面开出有纵深的门洞，门楣同步当前目标。地面显示最近的真实推导足迹。减少动态效果时直接更新状态。

悬停或键盘聚焦规则时预览实际作用范围：I 标出末尾字母，II 标出首字母后的整段，III 标出三个字母，IV 标出两个字母。多个位置可选时，DOM 片段与三维浅色选区同步。

Esc 优先关闭弹窗与章节地图；在花园内先取消选位，再关闭提示、观察线索和足迹面板，最后才返回序厅。

运行 `npm test` 验证动画字母来源映射、四条规则、重叠匹配、可达练习、分支保留、存档验证、展示限制和有界枚举中的不变量。发布前还应在浏览器走通改写、回退分岔、语言切换、刷新恢复、观察线索和窄屏布局。

## 渲染

- Three.js WebGL2，MeshStandardMaterial PBR 石墨灰材质。
- PMREM + RoomEnvironment 提供环境反射。三束正交 DirectionalLight 分别沿 Z、X、Y 轴照射同一件雕塑，使用实时 shadow map；G、E 分别落在两面墙，B 落在地面。没有使用字形贴图或合成轮廓，光源可独立开关。
- 默认开启 PCSS 柔光阴影：根据遮挡物深度估算半影，接近接收面时更锐利，距离增大时更柔和。桌面使用 16 次遮挡搜索及 48 次过滤，移动端为 12 / 24 次。使用接收面深度梯度修正，减少自阴影条纹；这是实时阴影贴图近似，不是路径追踪。柔光固定开启，不提供界面开关。
- GTAOPass 实时屏幕空间环境遮蔽，Poisson 降噪，OutputPass 色调映射和 FXAA。
- 根据用户选择不使用景深，保留雕塑的清晰轮廓；墙面阴影的柔化来自 PCSS。
- 雕塑为三个互相垂直的字形挤出体的布尔交集；模型使用自定义 Int16 量化二进制（约 700 KB），不是 glTF，因此不用 Draco；角色网格才走 Draco。
- 限制设备像素比以控制移动端开销；支持减弱动态和 WebGL 不可用时的文字入口。
- 桌面渲染像素比最高 2×，手机（宽度不超过 760px）最高 1.25×，均不超过屏幕原生 DPR。窗口尺寸或屏幕 DPR 变化时，画布和后处理使用相同的整像素分辨率，FXAA 的采样步长同步更新。

序厅保持安静，不提供音频试听或播放控件。中文字体使用 Noto Serif SC，无法联网时回退到本地宋体。没有使用书封、原书对白、埃舍尔图像或第三方实拍素材。

## 生成模型

默认雕塑由构建脚本写出：`npm run sculpture`（或 `node scripts/generate-sculpture.mjs [ABC]`），再 `npm run build`。字形来自 Three.js 示例的 Helvetiker Bold（仅拉丁大写）。

序厅提供三字输入框：访客可输入任意 A–Z 三连，在 Web Worker 中用同一套 CSG 求交替换网格，并刷新阴影。视角展签按字母显示书中相关彩蛋人名（角色、引用思想家与意象，如螃蟹、蒯因、芝诺）；分享链接支持 `?s=CAT`；失败（空网格等）会保留当前雕塑并提示。点击字母生成区的下载图标可直接导出当前雕塑为 STL（本地坐标）。输入要求仅在校验失败时提示，下载图标在悬停或键盘聚焦时显示说明。`npm run build` 会同时打包 `assets/app.js` 与 `assets/sculpture-worker.js`。

首屏精简：保留主标题、单句引导和入口；移除重复展签、标签及页脚标语。对白在切换视角或拖动后出现，恢复漫游视角时收起。完整书名和原创对白说明仍在章节地图内。

已移除右下角的独立漫游播放/暂停按钮，保留拖动和 G/E/B 视角切换。场景仍遵循系统的减弱动态偏好。

已加入 Blender 原创同行者模型，详见 ../characters/README.md。角色 GLB 经 Draco 压缩（约 120 KB + 70 KB），运行时用本地 `assets/draco/` 解码；重建未压缩导出后可运行 `npm run compress-characters`。两个模型具有骨骼与 Idle / Walk / Look 动画，角色标签和对白支持中英文；点击人物可交谈。首次载入短距离行走后停留，不持续循环走动。模型加载失败不会阻断序厅和其他交互。

停留时使用缓慢循环的骨骼待机动画：阿基里斯约 14 秒一段，包含呼吸、上身轻移和间歇转头；乌龟约 18 秒一段，包含探头、侧望和轻动前肢。交谈后恢复待机，遵循系统减少动态效果偏好。角色和 G/E/B 触发的对白共用固定的正文起点，避免文本长短或说话人变化造成跳位。

G/E/B 的观察按钮已改为字母加人名的展签，手机与桌面都默认显示；中文术语使用哥德尔、艾舍尔、巴赫，英文对应 Gödel、Escher、Bach。无障碍名称与悬停提示同时包含人名和观察方向。
